## 이 저장소에 대해

이 저장소는 GitHub 프로필 소개이면서 동시에 Next.js로 만든 포트폴리오 웹사이트의 소스코드입니다.

```bash
npm install
npm run dev   # http://localhost:3000
```

| 페이지 | 경로 | 내용 |
|---|---|---|
| 홈 | `/` | 소개, 강점 요약, 각 페이지로 이어지는 허브 |
| 내 프로필 | `/profile` | 기본 정보, 기술 스택, 핵심역량 |
| 프로젝트 | `/projects` | 학교·외부 프로젝트를 문제-해결 과정-결과-회고 순으로 정리 |
| 자격증 · 이력 | `/certificates` | 자격증, 학력, 대내외활동, 교육 이수 내역 |
